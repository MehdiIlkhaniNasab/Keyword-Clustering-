# قطب‌نما (Ghotbnama by Ronagh) — کیورد کلاسترینگ هوشمند و فروش‌محور

افزونه وردپرسی مستقل، هم‌خانواده و هم‌زبان با **سُکان**. فهرست خام کلمات کلیدی (دو ستون: کلمه کلیدی، حجم جستجو) را از گوگل شیت یا فایل می‌گیرد و این‌ها را تحویل می‌دهد:

- **کیورد ریسرچ به سبک دلنا**: یک شیت برای هر پیلار، بخش‌ها (لندینگ‌های اصلی، انواع، نگهداری، مشکلات…) و یک بلوک دوستونی برای هر کلاستر (کلمه | حجم + جمع). رنگ‌ها: سبز لندینگ اصلی، آبی لندینگ دسته/محصول، زرد بلاگ.
- **تقویم محتوا** در ساختار آژانس: M1، M2… با Writing Guide (Main Idea، KP، Title، Desc، Source)، پنج Out Link و پنج In Link (L/K)، Status، Publish Date و Link؛ به‌علاوه Ideas، B keyword و بریف هر مقاله.
- خروجی **اکسل** (بدون Composer) و **گوگل شیت** با همان فرمت (رنگ، ادغام، فیلتر، کشوی وضعیت، چک‌باکس، راست‌چین).

آدرس ابزار: `your-site.com/seo/cluster/` (ورود جداگانه، بدون قالب؛ مثل سکان در `/seo/plan/`).

## روش کار

| مرحله | کار |
|---|---|
| ۱. دریافت | تب «کلمات کلیدی» گوگل شیت (سرستون اختیاری؛ ستون‌ها با نام هم پیدا می‌شوند) یا فایل XLSX/CSV. حجم‌هایی مثل `1.2K`، `۱٬۲۰۰` و بازه Keyword Planner خوانده می‌شوند. |
| ۲. پاک‌سازی | یکدست‌سازی فارسی (ی/ک، نیم‌فاصله، آ/ا، اعداد)، ادغام املاهای یک کلمه، حذف برند رقبا و بازارگاه‌ها (دیجیکالا، ترب، باسلام، دیوار…)، کلمات منفی پروژه، کلمات بی‌ارزش (دانلود، فیلم، فال…) و حداقل حجم. **فیلتر هوش مصنوعی** برندهای ناشناخته و کلمات نامرتبط را پیدا می‌کند و نیت هر کلمه را می‌دهد. هیچ چیز بی‌صدا حذف نمی‌شود (تب «حذف‌شده‌ها» با دلیل و برگرداندن). |
| ۳. پیش‌خوشه‌بندی زبانی (رایگان) | هسته معنایی هر کلمه: حذف کلمات نرم (خرید، قیمت، روش، علت…)، ریشه‌یابی سبک بر اساس واژگان خود فهرست («گیاهان ← گیاه»)، ادغام غلط‌های املایی، مترادف‌ها (اسامی/نام/اسم…) و **کلمات عمومی داده‌محور** (مثلاً «گل» و «گیاه» در گیاهان؛ با مقایسه حجم «گل پتوس» و «پتوس»). ویژگی‌های تکرارشونده («پتوس ابلق»، «حصیری») لندینگ جدا می‌گیرند؛ دم‌بلندهای آموزشی به مقاله اصلی می‌پیوندند. |
| ۴. ۱۰ نتیجه اول گوگل | دو کلمه با N آدرس مشترک (۳ منعطف، ۴ متعادل، ۵ سخت‌گیر) یک صفحه‌اند → ادغام (مترادف‌ها هم پیدا می‌شوند)؛ گروهی که نتایجش متفاوت است تفکیک می‌شود. آدرس‌های «هاب» (صفحه اصلی که برای همه چیز رتبه دارد) نادیده گرفته می‌شوند و زنجیره‌سازی ممنوع است. از نتایج: نیت (تراکنشی/اطلاعاتی/ترکیبی)، نوع صفحه (دسته/محصول/مقاله)، سختی، جایگاه سایت، رقبا، سوالات PAA و جستجوهای مرتبط. |
| ۵. ساختار | هوش مصنوعی پیلارها و بخش‌ها را نام‌گذاری و کلاسترهای هم‌نیت را ادغام می‌کند؛ بدون هوش مصنوعی ساختار از داده‌ها ساخته می‌شود. |
| ۶. سایت | **افزونه رابط SeoReport Connector (نسخه ۱٫۲٫۰ به بعد)** روی سایت کارفرما با کلید آن: محصولات با قیمت و فروش، دسته‌ها، مقالات و سفارش‌های ۹۰ روز اخیر (میانگین سبد واقعی و فروش هر پیلار در امتیاز اثر می‌گذارد)؛ یا ووکامرس همین وردپرس، API عمومی ووکامرس/وردپرس سایت مشتری، API ووکامرس با کلید یا سایت‌مپ. اگر دسترسی نبود این بخش بی‌صدا کنار می‌رود. |
| ۷. نگاشت و امتیاز | صفحه هدف هر کلاستر، وضعیت (صفحه جدید / بهینه‌سازی / رتبه خوب)، کنیبالیزیشن (دو صفحه برای یک کلاستر، یک صفحه برای چند نیت، دو URL سایت در یک SERP، صفحه اشتباه رتبه‌گرفته) و **امتیاز فروش ۰–۱۰۰**. |
| ۸. شکاف محتوایی | برای کلاسترهای برتر: نیت کاربر، زاویه برنده، موضوعات اجباری، شکاف‌هایی که رقبا ندارند، سرتیترها، FAQ، عنوان و متا، تعداد کلمه، CTA و اسکیما. |
| ۹. تقویم | مقاله‌هایی که بیشترین جستجو را دارند و پیلارهای پولساز را تقویت می‌کنند، با تنوع ماهانه، تاریخ‌های شمسی روی روزهای انتخابی، لینک‌های خروجی به لندینگ‌های فروش و لینک‌های ورودی. |

### امتیاز فروش و بازگشت سرمایه

`امتیاز = ارزش^0.8 × (0.55 + 0.30 × سهولت + 0.15 × فرصت)`

- **ارزش**: ترافیک بالقوه (حجم × CTR جایگاه هدف) × وزن نیت (خرید ۱، ترکیبی ۰٫۶، مقایسه ۰٫۴۵، آموزشی ۰٫۰۸) — و برای ریال: × نرخ تبدیل × میانگین سبد (از قیمت محصولات همان پیلار یا تنظیمات پروژه). مقاله‌ها سهمی از ارزش لندینگ‌های پیلار خود می‌گیرند.
- **سهولت**: ۱۰۰ − سختی (دامنه‌های قوی، بازارگاه‌ها، عنوان‌های دقیق در ۱۰ نتیجه اول).
- **فرصت**: برد سریع (رتبه ۴ تا ۲۰)، صفحه موجود، یا صفحه جدید.
- اولویت: ۲۰٪ بالا P1، ۳۵٪ بعدی P2، بقیه P3.

## نتایج گوگل بدون هزینه زیاد

| حالت | هزینه | توضیح |
|---|---|---|
| رایگان | ۰ | زبانی + هوش مصنوعی؛ بدون SERP. |
| اقتصادی (پیشنهادی) | حدود ۱ تا ۲ دلار برای ۵۰۰۰ کلمه | فقط سر هر گروه، یک عضو مرزی گروه‌های بزرگ و کلمات بالای ۱۰۰۰ جستجو (حدود ۲۵ تا ۳۵٪). |
| کامل | حدود ۵ دلار برای ۵۰۰۰ کلمه | همه کلمات با حجم ۱۰ به بالا. |

- **Serper.dev**: ۲۵۰۰ درخواست رایگان هنگام ثبت‌نام (دو پروژه اول عملاً رایگان)، بعد حدود ۱ دلار برای ۱۰۰۰ درخواست.
- **DataForSEO** (Live، ایران/فارسی) و **SerpApi** هم پشتیبانی می‌شوند.
- کش نتایج بین همه پروژه‌ها مشترک است (پیش‌فرض ۳۰ روز) و سقف درخواست در هر اجرا قابل تنظیم است.
- Google Custom Search API به مشتری جدید داده نمی‌شود و از ۱ ژانویه ۲۰۲۷ (دی ۱۴۰۵) کاملاً بسته می‌شود؛ به همین دلیل استفاده نشده است.

## اتصال‌ها

- **هوش مصنوعی**: پیش‌فرض «همان مدل سکان» — اگر سکان روی همین سایت نصب است، کلید و مدل‌ها (GapGPT / سازگار با OpenAI یا Anthropic) مستقیم از تنظیمات سکان خوانده می‌شوند. یا تنظیم جداگانه. سقف بودجه ماهانه جدا دارد. هر پروژه ۵۰۰۰ کلمه‌ای با مدل‌های پیش‌فرض حدود ۰٫۱ تا ۰٫۴ دلار.
- **گوگل شیت**: سرویس اکانت (روش اصلی) یا اتصال گوگل سکان. شیت را با ایمیل سرویس اکانت به‌صورت Editor به‌اشتراک بگذارید و Google Sheets API را در پروژه Google Cloud فعال کنید. خروجی در تب‌های جدید نوشته می‌شود؛ تب‌هایی که قطب‌نما قبلاً نوشته جایگزین می‌شوند و تب‌های تیم دست نمی‌خورند.
- **شبکه**: حالت «هوشمند» مثل سکان؛ فقط گوگل، سرویس‌های SERP و AI خارجی از پروکسی وردپرس (`WP_PROXY_HOST`) رد می‌شوند.

## نصب

1. پوشه `ghotbnama` را zip کنید (`bin/build-zip.sh`).
2. وردپرس › افزونه‌ها › افزودن › بارگذاری؛ سپس فعال‌سازی.
3. به `your-site.com/seo/cluster/` بروید.

پیش‌نیاز: وردپرس ۶.۴+، PHP 8.0+ با `zip`، `openssl` و `mbstring` (و ترجیحاً `sodium` برای رمزنگاری کلیدها). پیوند یکتای «نام نوشته» توصیه می‌شود؛ بدون آن مسیرها از `?qtb_app=1&qtb_route=` کار می‌کنند. آدرس پایه با فیلتر `qtb_app_base` قابل تغییر است.

## ساختار کد

```
ghotbnama/
├── ghotbnama.php            بارگذاری ماژول‌ها
├── inc/
│   ├── core/                helpers · jalali · settings (+ خواندن تنظیمات سکان) · network (پروکسی) · install (جدول‌ها)
│   ├── models/              projects · data (payloadهای فشرده پروژه)
│   ├── connectors/          google · sheets · llm (همان API سکان) · serp (Serper/DataForSEO/SerpApi + کش) · store (ووکامرس/وردپرس/سایت‌مپ)
│   ├── engine/              lexicon · normalize · clean · precluster · serp-analysis · structure · score · gap · calendar · pipeline · edit
│   ├── export/              xlsx (نویسنده) · xlsx-reader · workbooks (مدل دو فایل) · gsheet (نوشتن در گوگل شیت)
│   ├── rest.php             API داخلی (اجرا، بارگذاری، ویرایش، دانلود، گوگل شیت، تست اتصال)
│   └── app/                 router · ui · actions
├── templates/app/           shell · login · denied · views/*
└── assets/                  CSS/JS خالص + فونت وزیرمتن
```

اجرای خوشه‌بندی مرحله‌ای و قابل ادامه است (هر درخواست حدود ۲۰ ثانیه)، پس پروژه‌های ۵۰۰۰ کلمه‌ای روی هاست معمولی هم کار می‌کنند.

## نقشه راه

- انتقال کلاسترها به تب «کلاسترینگ» و تقویم محتوای پروژه در سکان (خروجی CSV نقشه کلمات از الان آماده است).
- ورود مستقیم حجم جستجو از سئو سیگنال برای کلماتی که حجم ندارند.
- بازخوانی ماهانه رتبه‌ها و به‌روزرسانی خودکار اولویت‌ها.
